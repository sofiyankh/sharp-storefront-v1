# Sharp Storefront – Plateforme E-commerce Moderne

## Présentation du projet

**Sharp Storefront** est une application web e-commerce moderne développée dans le cadre d’un projet personnel visant à consolider mes compétences en développement front-end avancé et en intégration backend via Supabase.

Ce projet simule une plateforme complète de vente en ligne incluant :

- Une page d’accueil dynamique
- Un catalogue de produits avec filtrage
- Une page de détail produit
- Un système de panier interactif
- Un processus de commande (checkout)
- Une authentification utilisateur sécurisée
- Un espace profil utilisateur
- Un tableau de bord administrateur
- Une intégration base de données via Supabase

L’objectif principal était de concevoir une architecture propre, modulaire et évolutive, respectant les bonnes pratiques professionnelles.

---

À travers ce projet, j’ai souhaité :

- Approfondir ma maîtrise de React et TypeScript

## Technologies utilisées

Le projet repose sur les technologies suivantes :

- **Vite** – Outil de build moderne
- **React**
- **TypeScript**
- **Tailwind CSS**
- **shadcn/ui**
- **Supabase**

---

## Architecture du projet

Le projet est structuré de manière modulaire :

- `src/components` – Composants réutilisables
- `src/pages` – Pages principales de l’application
- `src/contexts` – Gestion d’état global (authentification, panier)
- `src/integrations` – Connexion à Supabase
- `supabase/migrations` – Scripts SQL pour la base de données
- `public` – Ressources statiques

Cette organisation permet une meilleure maintenabilité et évolutivité.

## Installation et exécution locale

### Prérequis

- Node.js (version 18 ou supérieure recommandée)
- npm

### Étapes d’installation

```bash
# 1. Cloner le dépôt
git clone https://github.com/sofiyankh/sharp-storefront-v1.git

# 2. Accéder au dossier du projet
cd sharp-storefront-v1

# 3. Installer les dépendances
npm install

# 4. Lancer le serveur de développement
npm run dev
````

L’application sera accessible localement via l’URL indiquée dans le terminal.
